# fcc-medical-records-validator
Medical Records Validator

A beginner Python project that checks the structure and format of medical record data.

Features

- Validate whether the input is a list or tuple.
- Check whether each record is a dictionary.
- Identify records containing unexpected data formats.
- Display validation messages for invalid records.

Concepts Practiced

- Lists, tuples, and dictionaries
- Functions and return values
- "isinstance()"
- "enumerate()"
- Keyword argument unpacking with "**"
- Conditional statements and loops

Requirements

- Python 3

How to Run

python medical_records_validator.py

Learning Goals

- Practice validating structured data.
- Understand nested data structures.
- Improve error handling and debugging skills.

Scope and Limitations

This is a learning exercise for Python data validation. It is not a production medical system and should not be used to validate real patient records.
